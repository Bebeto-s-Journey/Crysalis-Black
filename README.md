## Crysalis Black ( My own language ) 

The Crysalis project was created to understand how programming languages operate under the hood. Up until this version, I focused on learning how a computer interprets strings and executes logic. Although I haven't had the chance to go deeper yet due to my responsibilities at the studio where I work, this remains one of the most satisfying systems I have ever built.

To guide my learning in language design, I used Gemini and ChatGPT to help generate two structured books. It wasn't an obvious or easy path, but it allowed me to start building and learning effectively.
